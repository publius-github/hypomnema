# app-pkb

# app-pkb — планировщик недели + дневник + персональная база знаний

## Что это

Локальное Windows-приложение для личной продуктивности в формате «всё в одном»:
- недельный планировщик задач;
- дневник по шаблонам;
- персональная база знаний (PKB) на Markdown-заметках.

Приложение работает без обязательных облачных сервисов: данные хранятся локально.

UI приложения англоязычный (English-only): названия разделов, кнопок, статусов и системных сообщений отображаются на английском.

## Цель

- Планировать неделю целиком на одном экране.
- Вести личный дневник в структурированном формате.
- Хранить и редактировать базу знаний в Markdown внутри приложения.
- Объединить ручной ввод задач и конфигурируемые recurring-задачи через YAML.

## Информационная архитектура (левая таб-панель)

Слева находится вертикальная панель с четырьмя основными разделами:

1. **Dashboard (Tasks)**
2. **Journal**
3. **Knowledge Base**
4. **Settings**

### 1) Dashboard (Tasks)

Экран состоит из двух зон:
- Верхняя зона: недельная сетка (количество колонок настраивается в Settings, например 5/7/10) с задачами.
- Нижняя зона: пользовательские списки/проекты (кастомные списки задач).

Поддерживаемые операции:
- Ручное создание, редактирование и удаление задач.
- Drag & Drop между днями недели и пользовательскими списками.
- Подзадачи, цвета, время, напоминания, повторение.
- Markdown в описании задач.
- Чекбоксы статуса: To Do, Done, Postponed.
- Гибкое отображение выполненных задач: рядом с активными или отдельным блоком.

### 2) Journal

Раздел для ежедневных записей по пользовательскому шаблону (template).

Поведение:
- При открытии экрана "Journal Today" пользователь получает предложенный шаблон.
- Шаблон настраивается пользователем (структура блоков, вопросы, чек-листы).
- Запись дня сохраняется локально и редактируется как Markdown.

Пример блоков шаблона:
- Что сделал сегодня.
- Что было сложно.
- За что благодарен.
- Фокус на завтра.

### 3) Knowledge Base

Отдельное пространство персональной базы знаний:
- Указывается ссылка на локальную папку с заметками.
- Приложение отображает дерево заметок из этой папки.
- Заметки открываются и редактируются внутри приложения.
- Основной формат: Markdown (акцент на markdown-first workflow).

## Ключевые фичи

- Тёмная и светлая тема.
- Недельная сетка задач + кастомные списки.
- Drag & Drop для задач.
- Подзадачи (вложенная структура).
- Markdown в задачах, дневнике и базе знаний.
- Цвета задач для категорий.
- Время задач.
- Повторяющиеся задачи (recurring).
- Уведомления и напоминания.
- Полностью локальное хранение данных.

## Функциональные требования (вмерженный референс)

1. Ведение всех задач в Dashboard приложения с единым представлением задач в UI и локальным хранением данных.
2. Работа через чекбоксы со статусами: To Do, Done, Postponed.
3. Автоматическое разделение задач по спискам/контекстам (личное, рабочее и другие).
4. Поддержка задач на конкретные даты для планирования событий и дедлайнов.
5. Повторяющиеся задачи: ежедневно, еженедельно, ежемесячно, ежегодно.
6. Календарный недельный обзор: сегодня и ближайшие дни в одном экране.
7. Автоматический перенос просроченных задач в текущий день.
8. Явная пометка просрочки у незакрытых вовремя задач.
9. Автоматическая очистка выполненных одноразовых задач (по правилу/настройке).
10. Автоматическая защита от дублей при ручном вводе и генерации из правил.
11. Глобальное напоминание недели: одна фраза-фокус на период.
12. Ротация глобальных напоминаний по циклу.
13. Ежедневные напоминания по типу дня: рабочий, выходной, конкретный день недели.
14. Режим дневного расписания по времени: блоки дня с текущим и следующим фокусом.
15. Гибкое отображение выполненных задач: рядом с активными или отдельным блоком.
16. Группировка задач внутри дня по темам/категориям.
17. Автоматическая сортировка задач по типам и правилам.
18. Регулярное автообновление данных без ручной рутины.
19. Сохранение пользовательских правок после автообновлений и синхронизаций.
20. Единый итог: чистая и структурированная картина недели при открытии Dashboard.

## Источники задач

Приложение поддерживает два способа добавления задач:

1. **Ручной ввод в UI**
2. **Импорт из конфигурационного файла** (например, recurring-задачи)

При этом модель хранения может быть гибридной:
- основной слой: локальное хранилище задач приложения;
- слой автогенерации: правила из YAML-конфига;
- слой состояния UI: локальные метаданные (например, фильтры, порядок, режимы отображения).

Оба источника работают совместно: пользовательские задачи и задачи из конфига отображаются в едином интерфейсе.

## YAML-конфиг recurring-задач (cron)

### Формат

Предлагаемый файл: `config/recurring.yml`

Пример:

```yaml
tasks:
  - schedule: "0 0 1 * *"
    description: "Monthly"
    items:
      - "{05 Finance} pay bills for apartment"
      - "{05 Finance} pay bills for phone"
```

### Семантика полей

- `schedule`: cron-выражение запуска генерации задач.
- `description`: название/тип правила recurring.
- `items`: список задач, которые создаются по расписанию.

### Разметка категорий в item

Строка вида:

`{05 Finance} pay bills for apartment`

Интерпретация:
- `05 Finance` — имя списка/проекта (или категория).
- `pay bills for apartment` — текст задачи.

### Правила обработки

- При наступлении времени по cron приложение создаёт экземпляры задач.
- Нельзя дублировать уже созданные экземпляры за тот же период.
- Если конфиг изменился, новые правила применяются без потери пользовательских задач.
- Ошибки парсинга конфига показываются в UI (с номером строки и причиной).
- При автообновлении сохраняются ручные статусы и правки пользователя.
- Просроченные задачи переносятся в текущий день с сохранением отметки просрочки.

## Хранение данных

- Локально на устройстве (без обязательной регистрации и облака).
- Задачи, дневник и настройки хранятся отдельно от markdown-базы знаний.
- Markdown-база знаний хранится в выбранной пользователем папке.

## Минимальный MVP

1. Левая таб-панель: Dashboard / Journal / Knowledge Base / Settings.
2. Dashboard: недельная сетка сверху, кастомные списки снизу.
3. Journal: шаблон "today" + сохранение в Markdown.
4. Knowledge Base: подключение папки + чтение/редактирование Markdown.
5. Settings: настройка количества колонок недельной сетки и базовых параметров отображения.
6. Импорт recurring-задач из `config/recurring.yml`.

## Итог

app-pkb развивается из обычного to-do в персональную систему продуктивности: планирование, рефлексия и знания в одном локальном приложении с акцентом на Markdown и управляемую автоматизацию задач через YAML + cron.
